These are unofficial community docs for [lint-staged](https://github.com/lint-staged/lint-staged). The lint-staged project and its maintainers do not write, check or maintain this site. For the official text, read the [lint-staged README](https://github.com/lint-staged/lint-staged#readme).

## Why this site exists

lint-staged has no docs website. Its documentation is one long README. This site divides the same topics into pages that you can search, adds tested examples, and describes the behavior of the current version in detail. You can also ask questions with **Ask**, and AI agents can read the pages through `llms.txt` and an MCP server.

## Version and tests

| Item | Value |
| --- | --- |
| lint-staged version | 17.6.1 |
| Last check against the source code | 21 November 2026 |
| Test environment | Node.js 22.22, Git 2.54, macOS |

The pages are new text, written from the lint-staged source code and from test runs. Each command and configuration example on this site was run with lint-staged 17.6.1. Some configurations look the same as in the README, because a configuration often has only one correct form.

When a new lint-staged version changes behavior, we update the pages and this table.

## Found an error?

- An error on this site: open an issue in [revdoku-open-docs/open-docs-lint-staged](https://github.com/revdoku-open-docs/open-docs-lint-staged/issues).
- A bug in lint-staged itself: open an issue in [lint-staged/lint-staged](https://github.com/lint-staged/lint-staged/issues). The lint-staged maintainers do not read the issues of this site.

## Who publishes this site

Revdoku writes and hosts this site as part of its open docs program. The program publishes community docs for open-source projects that have no docs website. Revdoku makes docs portals with search and an AI support agent.

## For the lint-staged maintainers

This site is yours to take if you want it. We can:

- move the repository to the lint-staged organization, so that you control it;
- keep hosting it at no cost, with your project as the owner;
- change or remove any page;
- take the site down.

Open an issue in [revdoku-open-docs/open-docs-lint-staged](https://github.com/revdoku-open-docs/open-docs-lint-staged/issues), and we will do what you ask.
