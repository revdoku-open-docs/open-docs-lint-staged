# lint-staged community docs

Unofficial community docs for [lint-staged](https://github.com/lint-staged/lint-staged), published at https://lint-staged.revdoku.net.

The lint-staged project does not maintain these docs. The pages are original text, written from the lint-staged source code, and each example was tested with lint-staged 17.6.1.

- Found an error in the docs? [Open an issue](https://github.com/revdoku-open-docs/lint-staged/issues) or a pull request.
- Found a bug in lint-staged? Report it in [lint-staged/lint-staged](https://github.com/lint-staged/lint-staged/issues).
- lint-staged maintainers: we can move this repository to you, or take the site down. Open an issue.

The site is a [Revdoku](https://revdoku.com) docs site: `docs.json` holds the navigation, and each `.md` or `.mdx` file is a page. Each push to `main` publishes the site again.
